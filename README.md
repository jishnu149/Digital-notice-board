# Digital-notice-board
A responsive, interactive web application to showcase and manage VIT college events such as cultural fests, technical workshops, and sports meets. Built using HTML, CSS, and JavaScript.


🚀 Features

📋 Navigation bar with dynamic content loading (Home, About, Services, Contact)

🔍 Event search functionality by name

🗂️ Event filtering by category (Cultural, Technical, Sports)

🖼️ Dynamic event detail view with images

⏳ Countdown timer to event start

📝 Event registration form (UI only)

🎨 Responsive and clean UI with custom styles
